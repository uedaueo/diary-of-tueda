##  [igapyonv3] 日記生成ツール igapyonv3 を 2.0 系に更新

何年か前から日記の生成に [[igapyonv3]](https://github.com/igapyon/igapyonv3) を使わせて頂いていたのですが、maven plugin 版が jvm バージョン 11 でないと動かなくなっていて、ちょっと面倒になって日記の更新が止まっていました。

先日ふとみたら、[[igapyonv3]] が 2.0 系に上がっているじゃないですか。ただし、当面はmaven plugin 版は作成しないとのこと。となるとローカルのmaven repo にインストールするしかないですね、ということで、[igapyonv3]([[igapyonv3]](https://github.com/igapyon/igapyonv3)) を clone して main ブランチで以下を実行してサクッとインストール。

```
MAVEN_OPTS="-Djava.net.preferIPv4Stack=true" mvn -U install
```

旧版（v1.5.4）を使っていた日記リポジトリの pom.xml を、[igapyon さんの日記リポジトリのもの](https://github.com/igapyon/diary/blob/devel/pom.xml)を参考にして修正します。依存関係では新しいバージョンが出ているものもあるので、そこは最新に合わせてください。特に以下の設定が重要です。バージョン番号は先ほど clone してきた igapyonv3 リポジトリのものに合わせます。

```
		<dependency>
			<groupId>jp.igapyon.diary</groupId>
			<artifactId>igapyonv3</artifactId>
			<version>2.0.20260104.3</version>
		</dependency>
```

そして以下を実行して動作確認（同じ物を２回実行する）。ちなみに jvm は OpenJDK 21 を使ってます。

```
mvn clean exec:java@igdiary antrun:run
mvn clean exec:java@igdiary antrun:run
```

settings.src.md で次の設定をしてひな形の自動生成を止めているので、新しい日記を生成するには、まずひな形を作る所から（[この辺](https://uedaueo.github.io/diary-of-tueda/2023/ig230413.02.html)を参照）。特に今回は今年初めての日記なので、2026 ディレクトリを作成する所からです。そしておもむろに日記を生成します。

```
mvn clean exec:java@igdiary antrun:run
mvn clean exec:java@igdiary antrun:run
```

git status で更新されたファイルを確認してあげると、なんとなく日記が生成されている事がわかります。html は target/md2html の下に生成されているのですが、とりあえず commit として github pages のリポジトリに push しておきます。

なお、以前のバージョンでは

```
mvn compile
mvn compile
```

としていたのですが、現在の igapyonv3 のドキュメントでは exec と antrun でやれとなっているので、おとなしくしたがっておきます。
